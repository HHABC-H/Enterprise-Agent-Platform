# 企业级 AI 智能体平台能力说明

## 产品定位

企业级 AI 智能体平台面向企业内部知识问答场景，目标是让文档、检索证据、回答过程和人工决策可以被统一管理。平台强调“先找到可用证据，再生成答案”，而不是直接根据问题猜测内容。

## 文档处理

当前最小版本支持 Markdown 文档。文档提交后会记录租户、来源、版本、权限标签和允许用户，并按照 Markdown 标题层级切分为多个 Chunk。每个 Chunk 会保留标题路径，便于检索结果携带完整上下文。

当同一个文档再次提交完全相同的正文时，系统会根据内容哈希识别为重复版本，避免重复切分、重复建图和重复写索引。

## 混合检索

平台可以并行获取向量检索和全文检索候选，再使用 RRF 方法进行融合排序。检索结果不是直接作为答案，而是要经过租户、用户权限、证据充分性和来源校验。

在 local profile 下，平台使用内存实现完成演示；在 Docker profile 下，可以按配置接入 ParadeDB 全文检索、Neo4j 图谱、Redis 会话记忆和 RabbitMQ 增量入库。

## 可信问答

回答流程包含规划、执行、反思、重新规划和完成等状态。问题能够从知识库召回充分证据时，平台会生成带引用证据的回答；如果没有足够证据，平台会明确拒答，不编造文档中不存在的事实。

回答结果包含以下信息：

- 回答正文或拒答原因；
- 引用的文档、Chunk 和来源；
- 检索与工作流状态轨迹；
- 可用于日志关联的 Trace ID。

## 人工审批

对于需要人工确认的回答，可以在请求中开启“回答前需要人工审批”。检索证据充分后，流程会进入 `WAITING_APPROVAL`，暂不生成最终答案。审批人核对证据后，可以通过或拒绝该工作流。

## 使用建议

提问时尽量使用知识库中的业务词汇，例如“平台支持什么文档”“证据不足时如何处理”“文档如何按标题切分”。对于知识库中没有出现的问题，系统应返回拒答，这属于安全行为而不是异常。

# 知识检索安全规范

## 租户隔离

每一份知识文档都属于一个租户。检索请求必须携带租户标识，平台只允许在当前租户范围内召回文档、Chunk 和关系。不同租户即使使用相同关键词，也不应互相看到知识内容。

## 用户权限

知识文档可以配置公开权限标签，也可以配置用户专属权限。用户专属文档只允许匹配的用户 ID 进入候选集合。权限过滤发生在答案生成之前，模型不应接触未授权的文档正文。

当用户没有权限访问某份文档时，系统应表现为没有可用证据，并返回拒答或空结果，而不是通过错误消息泄露文档标题、机密词或正文片段。

## 证据边界

平台的回答必须能够关联到检索证据。证据不足时，系统返回明确的拒答原因，不应该补充知识库之外的推测。评测问题“火星基地的管理员是谁？”可以用于验证这一边界，因为该事实不属于平台知识库。

## 版本隔离

同一文档可以拥有不同版本。关系查询和检索结果必须限定租户、文档和版本，较旧版本的数据不能覆盖较新版本。增量入库使用内容哈希和幂等键降低重复事件造成的副作用。

## 审批安全

人工审批需要满足以下条件：

1. 审批人必须属于允许的审批人列表；
2. 审批意见不能为空，且不能超过 500 个字符；
3. 审批版本必须与检查点版本一致；
4. 已处理、过期或不存在的工作流不能重复审批；
5. 审批通过前不生成需要人工确认的最终动作。

## 敏感信息保护

日志和检查点只保留必要的摘要、状态、数量、时间、版本和 Trace ID，不应记录模型密钥、数据库密码、完整敏感对话和未授权文档正文。私有连接配置应放在本机忽略文件或环境变量中，不提交到代码仓库。
